如何构建
--------
Windows（推荐，无需 bash/python3）：

    powershell -ExecutionPolicy Bypass -File tools\build.ps1
    powershell -ExecutionPolicy Bypass -File tools\build.ps1 -Platform ARM64
    powershell -ExecutionPolicy Bypass -File tools\build.ps1 -Configuration Debug

    产物：artifact-<平台>\PCLCE For SGU <版本>.exe，并自动同步一份到 dist\

拿不到网络时（离线还原）：

    powershell -ExecutionPolicy Bypass -File tools\build.ps1 -RestoreSources <本地 nupkg 目录>

前置条件：.NET SDK 10（可用 `dotnet --list-sdks` 确认）；
构建脚本会先校验本地化 XAML 无重复键，再打包插件，最后 publish。

发版
----
1. 改 Plain Craft Launcher 2\metadata.json 的 version.suffix 与 version.code（正式版把 suffix 置空）
2. 在 DOWNSTREAM-CHANGES.md 加小节（版本号 / 产物大小 / SHA-256）
3. 在 HANDOVER.md §0 加修订小节、更新 §2 状态表
4. 构建 → 抽查产物字符串 → 更新根目录快捷方式 → 重新打交接包

交接注意事项
------------
* 单实例互斥：启动器在跑时新进程会直接退出，因此界面改动无法自动化验证，必须人工点一遍。
* tools/build.ps1 与 plugins/package.ps1 必须保持 UTF-8 with BOM（否则被 PS 5.1 按 GBK 解码而解析失败）。
* 语言文件（PCL.Core/App/Localization/Languages/*.xaml）里出现重复 x:Key 会让界面所有文字变空，
  构建已加门禁；手工改完记得跑一次构建确认打印「本地化键校验通过」。
* snapshot-26 有「界面文字全空」的缺陷，已被 snapshot-27 取代，历史 exe 不要分发。
* 当前 GUI 观感、陶瓦联机均未实测 —— 这是接手后最该补的两块。
* 详细待办与待拍板事项见 HANDOFF-2026-10-25.md §3 / §4 / §8。
